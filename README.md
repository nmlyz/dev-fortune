A tiny program that writes one fortune-cookie line for developers to a
text file. The line is a single sentence of at most 120 characters: a
short, balanced piece of wisdom about legacy code, stating a fate with
a quiet double meaning that rewards a second read.

Bounty: https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
